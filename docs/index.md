## Custom Project

### Dataset
I used a dataset with yearly alcohol consumption by state, including beer, spirits, and total drinks.

### Signals
I created:
- beer_share_signal
- spirit_share_signal
- total_selected_signal
- total_drinks_signal

### Experiments
I replaced the original system data with alcohol data and tested signals using beer and spirits only.

### Results
The code created a new CSV with signals and a chart showing trends over time.

### Interpretation
The signals make the data easier to understand and show how alcohol consumption changes over time.
